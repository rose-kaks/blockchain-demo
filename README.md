## What is a Blockchain?
- A blockchain is just a list of "blocks".
- Each block contains some data + a link (hash) to the previous block.
- Once a block is added, changing it breaks the chain → very secure.

## Features
- Genesis block
- Simple mining with Proof of Work (finding a hash starting with zeros)
- Chain validation (detects tampering)
- No external libraries needed
